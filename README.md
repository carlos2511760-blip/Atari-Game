# 🕹️ Pac-Man Web Edition

Bem-vindo ao repositório do **Pac-Man Web**, uma recriação do clássico arcade desenvolvida utilizando o motor/framework **Antigravity**. Este projeto foi criado para ser executado diretamente no navegador e está pronto para ser hospedado via GitHub Pages.

## 📝 Sobre o Projeto

Este projeto consiste em uma implementação fiel da mecânica do Pac-Man original, onde o jogador deve comer todas as pastilhas do labirinto enquanto foge de quatro fantasmas coloridos.

- **Motor de Desenvolvimento:** Antigravity (Vanilla JS / Canvas).
- **Linguagem:** JavaScript / HTML5 / CSS3.
- **Hospedagem:** GitHub Pages.

## 🚀 Como Executar o Jogo

### Pré-requisitos
Você não precisa instalar nada complexo para jogar, apenas um navegador moderno (Chrome, Firefox, Edge ou Safari).

### Rodando Localmente
1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` no seu navegador de preferência.

## 🛠️ Desenvolvimento e Deploy

Esta seção descreve as ferramentas e o fluxo de trabalho utilizados para manter o jogo.

### Ferramentas Utilizadas
- **Antigravity:** Framework utilizado para a lógica de física, movimentação e renderização dos sprites.
- **GitHub Desktop:** Interface gráfica para controle de versão e envio de alterações (commits).
- **GitHub Pages:** Serviço de hospedagem estática para disponibilizar o jogo online.

### Fluxo de Atualização (GitHub Desktop)
Para atualizar o jogo no ar, siga estes passos no GitHub Desktop:
1. **Changes:** Após salvar suas alterações no Antigravity, abra o GitHub Desktop. As mudanças aparecerão na aba "Changes".
2. **Commit:** Escreva um resumo da alteração (ex: "Ajuste na velocidade dos fantasmas") e clique em **Commit to main**.
3. **Push:** Clique em **Push origin** para enviar os arquivos para o servidor do GitHub.
4. **Deploy:** Uma vez que os arquivos estão na branch principal, o GitHub Pages atualizará o link automaticamente em alguns minutos.
